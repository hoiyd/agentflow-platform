---
name: report-review
description: Review a supplied report before publication and identify unsupported claims or unresolved questions.
disable-model-invocation: true
---
Review only the report and evidence provided by the user or authorized Tools.
Separate verified statements, unsupported claims, and open questions. Preserve
uncertainty and source attribution. Return a concise review with those three
headings; do not rewrite or publish the report unless separately requested.
This method never grants Tool access or authorizes external actions.
